# Project Rules

This is a 3-day hackathon MVP.

Priorities:
1. Working demo
2. Business value
3. Reliability
4. Simple architecture
5. Visual polish

Rules:
- Do not overengineer.
- Prefer simple libraries.
- Avoid unnecessary abstractions.
- Avoid changing working code unless necessary.
- Run the app after important changes.
- Fix errors before declaring a task complete.
- Explain major architectural changes before implementing them.
- Preserve existing functionality.
